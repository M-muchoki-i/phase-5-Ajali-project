# 🚨 Ajali App – Incident Reporting System

## 📌 Overview
Ajali App is a full-stack incident reporting system that allows users to report, track, and manage incidents efficiently. The system supports role-based access, enabling both regular users and administrators to interact with the platform based on their permissions.

---

## 🎯 Problem Statement
Many communities lack a centralized and efficient way to report and manage incidents. Ajali App solves this by providing a structured platform for reporting, monitoring, and responding to incidents.
